# agent-skills — koleksi skill AI agent oleh motumona

> Kumpulan skill (instruksi + referensi + skrip) untuk AI coding agent:
> bug bounty, trading, penulisan akademik, Web3/Agentic wallet, dan
> workflow sehari-hari. Dipakai harian oleh Muse untuk @motumona.

Snapshot: 21 November 2026. Fase 1 + fase 2 + fase 3: 83 folder, 391 file `SKILL.md`.

## Cara pakai

1. `git clone https://github.com/motumona/agent-skills`
2. Salin folder skill yang dibutuhkan ke `~/.claude/skills/` (Claude Code)
   atau `~/workspace/custom-skills/` (Muse).
3. Baca `SKILL.md` tiap skill untuk cara pakainya.

## Karya sendiri vs upstream

- `skills/` — ditulis Muse untuk motumona (MIT).
- `upstream/` — karya penulis lain, didistribusikan ulang sesuai lisensi
  aslinya; lisensi + copyright asli dipertahankan di tiap folder.

## Keamanan

Skill bug bounty / pentest di sini hanya untuk target yang kamu punya
izin mengujinya (authorized testing). Jangan dipakai untuk menyerang
sistem orang lain.

lisensinya masing-masing, yang dipertahankan di tiap folder.
